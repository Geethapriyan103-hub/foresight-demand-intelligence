<h2>🚀 About FORESIGHT</h2>

<p>
<b>FORESIGHT</b> is an AI-powered inventory intelligence platform designed
to transform historical sales and inventory data into actionable business insights.
</p>

<p>
Instead of simply showing what happened in the past, FORESIGHT focuses on
understanding <b>what is likely to happen next</b> and helping users make
better inventory decisions.
</p>

<h2>⚡ Run Locally</h2>

<pre>
git clone https://github.com/Geethapriyan103-hub/foresight-demand-intelligence.git

cd foresight-demand-intelligence

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

python -m streamlit run app.py
</pre>

<p>
The dashboard will be available at:
</p>

<pre>
http://localhost:8501
